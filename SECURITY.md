# Security

Mobile Tmux can type into terminals and run shell commands as the user it runs as, so its security matters a lot.

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button on the repository's Security tab,
rather than a public issue. Include steps to reproduce. You can expect an acknowledgement within a few days.

Supported: the latest commit on `main`.

Deployment guidance (what to expose, and how) is in the README under "Signing in and security".
